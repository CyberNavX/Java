## 1. Calculadora de Presupuestos
* Aprendi a usar Scanner (Comentando la explicacion dentro de CalculadoraPresupuesto)

* Entendi a usar paquetes en java, 'package Ejercicios;' 
    **Sintaxis** 
    * [~/Escritorio/Programacion/Java$ javac Ejercicios/...]

    la ejecucion se debe hacer desde la carpeta raiz, del proyecto, en este caso es Java (repositorio de GitHub).
